## About Me

My development journey has been shaped by building applications, exploring technologies, and figuring out how different pieces of software work together.

I started with JavaScript and gradually expanded into backend engineering, frontend development, databases, cloud infrastructure, and AI integrations.

One thing I particularly enjoy is working on problems that don't have a ready-made solution. Whether it's understanding an unfamiliar library, structuring a complex backend workflow, handling asynchronous operations, or connecting an LLM to an application, I like exploring the problem, understanding the underlying concepts, and making things work.

I have worked on full-stack applications involving authentication, multi-tenant architecture, payment workflows, background processing, real-time communication, and AI-powered features.

**My approach to engineering:**

- Understand the problem before choosing the technology.
- Learn unfamiliar tools by exploring how they actually work.
- Focus on maintainable architecture rather than just making features work.
- Understand how components communicate across an application.
- Treat debugging and technical challenges as opportunities to understand systems more deeply.

## Featured Projects

### 01. CareerHub — AI-Powered Placement & Recruitment Platform

**A multi-tenant SaaS platform connecting colleges, students, and companies through structured recruitment workflows and AI-powered career tools.**

CareerHub brings college placement management, job opportunities, student applications, resume improvement, and AI-powered interviews into one connected platform.

**Key Engineering Work**

- Designed role-specific workflows for Super Admin, College Admin, Students, and Companies.
- Implemented authentication, JWT-based authorization, and organization-aware access control.
- Developed job management, student applications, and eligibility evaluation workflows.
- Integrated an AI Resume Builder with content generation, rewriting, ATS-related analysis, and PDF generation.
- Developed AI-powered interview workflows involving question generation, real-time communication, speech processing, and candidate response evaluation.
- Used LangChain and LangGraph for AI-related orchestration workflows.
- Implemented asynchronous processing using RabbitMQ and dedicated workers.
- Applied Clean Architecture, Repository Pattern, Dependency Injection, and SOLID principles.
- Containerized services and deployed backend infrastructure using Docker, AWS EC2, and NGINX.

**Technology:** Next.js · React · TypeScript · Node.js · Express.js · MongoDB · Redis · RabbitMQ · Docker · AWS · Gemini · Ollama · LangChain · LangGraph · LiveKit · Deepgram · Cartesia
